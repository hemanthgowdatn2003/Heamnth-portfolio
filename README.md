# Hemanth Gowda T N — Portfolio

Responsive personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Included
- Profile photo
- Resume PDF download
- Email, phone, WhatsApp, LinkedIn, and GitHub links
- IEEE Xplore link for the snake detection publication
- Projects, skills, research, experience, and education sections

## Deployment
Upload the contents of this folder to a GitHub repository and import it into Vercel as a static site. Deploy both `index.html` and the complete `assets` folder.
